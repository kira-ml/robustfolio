# Figures

These PNGs are static renders from the published run. They are drawn by
`scripts/make_figures.py`, which needs a run directory containing
`net_excess_returns.csv`. That return series is deliberately not committed: it is
derived from the third-party snapshot, and the snapshot is not distributed.

They are therefore **not regenerated by CI** and are not a substitute for the
committed tables in `docs/published-run/`. Regenerating them requires a local
snapshot and a run directory.
