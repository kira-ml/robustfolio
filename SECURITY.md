# Security policy

This repository contains research code, committed derived tables, and public
documentation. It does not contain credentials, API keys, personal data, or raw
market-data snapshots.

If you believe you have found a security issue, please use GitHub's private
vulnerability reporting for this repository rather than opening a public issue.
Include the affected file or command, the expected behaviour, and the smallest
reproduction you can provide.

The project's data policy is in [`docs/data_licenses.md`](docs/data_licenses.md).
Please do not send or attach a market-data snapshot when reporting an issue.
