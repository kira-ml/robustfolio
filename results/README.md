# Results

`phase1_results.csv` is a **historical Phase 1 record**. It was produced before the
current snapshot-based harness and is not regenerated by the current scripts.

The current public tables are in [`../docs/published-run/`](../docs/published-run/).
Other run directories under `results/` are local scratch output and are ignored by
git; they are not part of the published record.

The market-data snapshot is not distributed; see
[`../docs/data_licenses.md`](../docs/data_licenses.md).
