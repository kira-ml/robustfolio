# Publication audit — 2026-11-08

**Status:** Pre-publication audit. No DOI has been published. The Zenodo record is a private draft.

This note records the evidence behind the v1.1.1 claim correction. It is written so a reader can check the correction rather than trust it.

## 1. Verdict

The code, published tables, and archive are technically reproducible. The country sample's **confirmatory** label is not supported by the repository's timestamp evidence. The sample is therefore reported as a **pre-specified external replication**, not a confirmatory test.

This is a claim-label correction. No return, metric, verdict, or method changes.

## 3. Country claim: what the timestamps show

| Event | Timestamp (local, 2026-11-05) |
|---|---|
| Protocol file created | **19:49:16** |
| Country snapshot created | 19:49:50 |
| Country outcomes/decisions written | **19:51:35** |
| Country result note created | 19:53:15 |
| Protocol file last written | **20:08:45** |
| Commit `3120938` (protocol + results together) | 20:09:27 |
| Commit `17cd61a` (“Mark the country sample as confirmatory”) | 20:15:08 |

The protocol file was created before the snapshot, which is consistent with an early draft. But its **final content was written after the results**, and the protocol and results were committed together. The repository therefore cannot establish that the protocol text was frozen before execution.

A wider search covered the user profile, project drives, editor history, temporary files, PDFs, and DOCX files: **26,623 files**, no pre-run copy. Git history, dangling objects, reflog, and the Recycle Bin contain no earlier version.

**Decision:** the country sample is a **pre-specified external replication**. Its protocol is dated 2026-11-05, but the freeze is not independently verified. It is not labeled confirmatory.

If a pre-run copy is later found, this decision can be revisited only with the copy, its timestamp, and a hash. The label must not be restored from memory.
